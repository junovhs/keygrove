What this is

Relaxed QWERTY is a free typing trainer that teaches the Relaxed QWERTY 1.0 method on an ordinary QWERTY keyboard: accuracy first, speed as a consequence.

Relaxed QWERTY is free. You type short runs through a map of trails; each trail adds a few keys and only opens the next when you are accurate on the ones before.
