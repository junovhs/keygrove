The method

Relaxed QWERTY keeps the standard QWERTY map and a stable finger-to-key relationship, but lets the hands move naturally instead of holding the rigid historical home-row posture — the bottom row in particular is reassigned (Z ring, X middle, C index, B right index).

You learn Relaxed QWERTY 1.0. Traditional touch typing is a selectable alternative in Settings for people who already type that way.
